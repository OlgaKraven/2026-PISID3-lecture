# Разработка и проверка ПиДИС

## Запуск

Node.js 24. Из корня проекта:

```sh
npm ci
npm run build
npm run preview -- --port 4176
```

Открыть <http://127.0.0.1:4176/2026-PISID3-lecture/>. Разработка: `npm run dev`. `BASE_PATH` задаёт путь размещения. Через `file://` сайт не запускается.

## Управление

Тур по кнопкам отключён, включая запуск через `?tour=1`. Перелистывание: стрелки под слайдом, ←/→, PageUp/PageDown, Home/End; свайп влево открывает следующий слайд, вправо — предыдущий. Поля и диалоги сохраняют собственное управление.

В каталоге у каждой темы есть **«Открыть эксперимент»**; в лекции и панели преподавателя — **«Эксперимент»**. На вводном слайде нажмите **«Начать эксперимент»**, затем **«Развернуть эксперимент»** для большого рабочего поля. Изменяйте условия, наблюдайте анимацию и сохраняйте результаты запусков для сравнения. Есть исходный набор, изменённое условие и проверка границы.

Вход и редактор курса исключены из интерфейса и сборки. Убраны кнопки повтора и отключения анимации, «Изучено», «Повторить», «Закладка» и текст «Вперёд». Стрелки сохраняют доступные подписи. Режим двух окон сохранён: параметры, результаты, развёрнутая лаборатория и ход анимации синхронизируются с аудиторией. Анимация запускается при изменении условия или действии и учитывает системное уменьшение движения.

В заданиях с несколькими ответами 6–8 вариантов, из которых правильны 2, 3 или 4. В соответствии 6–8 пар: можно выбирать ответ, менять порядок и перемешивать оба списка. Второй экран показывает полные тексты выбранных пар и получает изменения порядка и прокрутки. Новая попытка меняет порядок вариантов.

## Авторские источники

[Гайд автора](authoring-guide.html) · [Справка преподавателя](public/guide.html) · [Аудит текущей редакции](docs/EDITORIAL_REVIEW.md)

Определения: `authoring/original-course.json`; разборы: `authoring/worked-cases.mjs`; объяснения и дополнительные случаи: `authoring/teaching-guidance.mjs`, `authoring/expanded-blocks.mjs`; схемы: `authoring/case-visuals.mjs`. Лаборатории: `authoring/experiments.json`, `authoring/laboratory-config.mjs` и `authoring/experiment-visuals.mjs`. Генератор `scripts/generate-content.mjs` обновляет курс, задания, лаборатории и заметки одновременно. Индивидуальные заметки: `authoring/teacher-overrides.json`. Старые ссылки: `authoring/slide-aliases.json`.

В каждой лекции 88–89 слайдов: исходные знания, объяснение подхода, смысл и границы восьми понятий, пошаговые примеры, четыре полных случая, дополнительный независимый случай и лаборатория с разбором. Заметки содержат ход объяснения, вопросы группе, ожидаемые ответы и типичные ошибки, чтобы тему мог вести начинающий преподаватель. 624 ссылки на ранее объединённые слайды сохранены. Повтор не удаляется, если он необходим для объяснения, самостоятельной попытки или переноса в новую ситуацию.

Действующий интерфейс — `src`; исторические `app`, `components`, `hooks`, `lib` не входят в сборку. Движок закреплён архивом `vendor/olgakraven-lecture-engine-0.2.0-course.5.tgz`: ограничение размеров заданий расширено до 4–10 вариантов и пар. Слой оформления — `scripts/presentation-plugin.ts`, самостоятельные случаи — `authoring/practice-cases.mjs`. Исходный архив 0.2.0 сохранён; `node scripts/prepare-engine.mjs` воспроизводит расширение, после него нужен `npm install` для согласования lock-файла. Адаптеры в `scripts/*-plugin.ts` проверяют сигнатуры движка и останавливают сборку при несовместимом обновлении.

Полный сценарий `public/teacher-pack.json` публичен; все 2 299 заметок согласованы с текущими слайдами. В панели показан сценарий без служебной версии. Личные правки прежней редакции остаются в отдельном хранилище браузера и не перекрывают новый сценарий; экспортируйте их перед сменой версии. Окно аудитории не загружает сценарий. Эксперименты и их параметры являются учебными моделями; для печати используются статические схемы.

## Проверки

```sh
npm run generate:content
npm run check:generated
npm run check:methodology
npm run audit:content
npm run check:readiness -- --strict --teacher=public/teacher-pack.json
npm run test:notes
npm run lint
npm run build
npm run check:privacy
```

При работающем preview: `npm run test:interactions`, `npm run test:tour`, `npm run test:smoke`, `npm run test:visuals`, `node scripts/check-startup-notes.mjs`, `node scripts/render-audit.mjs`, `node scripts/check-resources.mjs`. `SITE_URL` переопределяет адрес. Нужен Chromium Playwright либо Edge. Старый `scripts/audit-content.mjs` проверяет архив миграции.

PDF: `npm run export:pdf`; одна лекция: `npm run export:pdf -- --topic 16-decision-matrix`. Результат — `outputs/pdf/student`.

GitHub Actions публикует Pages после обновления main; публикуется проверенная завершённая редакция. Офлайн-копия не включает внешние файлы Яндекс Диска. РПД и официальные часы не предоставлены; время сценария не является расписанием пары. [Источники и границы проверки](docs/SOURCE_AUDIT.md).

## Самостоятельные случаи и текст преподавателя

104 случая используют собственные исходные данные и два зависимых проверяемых результата. Свободное обоснование оценивается отдельно по видимым критериям. Разбор раскрывается после попытки. Пакеты текстов находятся в `docs/teaching/`; `alignment.json` хранит точный источник, ID, порядок и привязку. Экспорт: `node scripts/export-teaching.mjs`.

Браузерная проверка текущей редакции: `node scripts/review-release.mjs layout`, `cases`, `show`, `tasks`. Фактический результат хранится в соответствующем `reports/release-*.json`.

Единый слой инфографики — `src/infographic-theme.css`: цветовые роли для SVG, таблиц, мобильного текста, лабораторий и развёрнутых схем. Проверка `npm run test:design` сверяет фактические цвета всех схем в двух темах; предметные численные образцы контраста не перекрашиваются.
