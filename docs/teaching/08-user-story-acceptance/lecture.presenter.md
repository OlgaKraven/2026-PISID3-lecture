## Слайд 20. Кому нужна история

Начальник смены хочет видеть незавершённые приёмки, чтобы распределять сотрудников. Оператор сканирует отдельные партии.

Откроем «Интерактивную схему». Сначала запишите прогноз, затем заполните два результата артефакта: роль истории; объект цели. Первый результат проверяется до второго. После попытки разбор можно раскрыть отдельной кнопкой; обоснование обсудим по указанным критериям.

**Подготовка:** Учебный пример WMS; значения условные. Кладовщик получает задание на подбор, сканирует партию, подтверждает количество и формирует накладную.

**Разбор для преподавателя:**

Шаг 1: начальник смены. Берите владельца цели.
Шаг 2: незавершённые приёмки. Не заменяйте цель действием оператора.

История относится к распределению работы начальником смены; сканирование может быть другой историей.
