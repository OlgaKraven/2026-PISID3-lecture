# Проверка редакции и покрытия

`npm run generate:review` создаёт черновик и карту реальных блоков. Карта
не выставляет содержательное одобрение. `npm run check:audit` проверяет полный
состав по результатам выполненного прохода в `authoring/audit-reviews.json`.
Эта команда обязательна в GitHub Actions перед публикацией.

Отпечаток каждого блока включает порядок и содержание слайдов, весь текст
преподавателя, метаданные, словарь, вложенные SVG и их локальные зависимости,
шрифты, конфигурации упражнений и реализацию показа. Изменение без смены
`contentVersion` также аннулирует прежний результат. Пропущенный блок,
открытый дефект, заменённый файл доказательства или неполная проверка блокируют
выпуск. Показатели количества и успешная сборка не дают одобрение автоматически.

Помощник перенесён из поддерживаемого навыка `teaching-audit` проекта BrainM.
Источник и точный отпечаток указаны в `scripts/audit-gate-source.json`;
несовпадающая копия не запускается. Во время CI доступ к BrainM и сеть для
этой проверки не требуются. Нужен Python 3; путь можно задать переменной `PYTHON`.

Результаты содержательной проверки — в `docs/BLOCK-REVIEW-2026-10-25.md`.
В карте названы конкретные выводы каждого вопроса и связанные доказательства.
Генератор не должен обновлять её статусы или переносить старый отпечаток на
новую схему. Проверяющий сначала рассматривает изменившееся содержание и выполняет
затронутые сценарии. После этого оформляется новая запись; перестроить инвентарь
вместо проверки недостаточно.

Текстовые файлы реализации закреплены с LF в `.gitattributes`, бинарные ресурсы
сохраняют точные байты. Это предотвращает различие отпечатков при checkout
Windows/Linux. Нормализация только CRLF→LF проверена повторной сборкой:
состав и байты клиентской сборки остались прежними. Предметные данные при этом
не менялись.

Публичная приёмка выполняется после успешного deploy и хранится отдельно от
локальной: `check-published-source.mjs`, `check-public-show.mjs`,
`check-public-answers.mjs` и предметные сценарии. Локальное одобрение не выдаётся
за проверку сайта. Файлы карты и отчётов не попадают в учебный интерфейс.
