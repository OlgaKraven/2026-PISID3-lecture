# Самостоятельное прохождение ПиДИС

Редакция `pisid3-2026.10.25-student`. Экспертный проход охватывает 26 лекций: доступные студенту определения, примеры, исходные схемы, изменённые условия, задания и обратную связь. Скрытый сценарий не используется как недостающее объяснение. Это проверка материала, а не апробация с реальной группой.

## Учебный ход

Исходные схемы остаются на местах объяснения. Перед самопроверкой каждого вопроса расположен паспорт с одной кнопкой «Начать эксперимент». Эксперимент содержит два явно заданных случая; переключение возвращает к исходному шагу, прежний результат не переносится на новые условия. Возврат по шагам скрывает последующие результаты. Сохранённые запуски сохраняют условие и прогноз, чтобы можно было объяснить различие.

В этом же окне студент получает новые данные и два связанных результата. Первый проверяется до второго; его изменение отменяет прежнее подтверждение зависимого результата и раскрытый ответ. Ошибочный ввод получает предметную подсказку, правильный — основание проверки. Полный разбор доступен после попытки отдельной командой. Свободное обоснование сопоставляется с критериями и не объявляется автоматически верным по факту заполнения.

Печать сохраняет исходные схемы, разборы изменённых случаев, условия самостоятельной проверки и ссылку на эксперимент. Ключи основных заданий и личные заметки в PDF не выводятся.
