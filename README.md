# ПиДИС · 3 курс

26 лекций МДК.05.01 «Проектирование и дизайн информационных систем», 5–6 семестры. Учебный кейс — WMS. 1 883 слайда, 208 понятий, 104 вопроса и 416 заданий.

## Запуск

Node.js 24. Из корня проекта:

```sh
npm ci
npm run build
npm run preview -- --port 4176
```

Открыть <http://127.0.0.1:4176/2026-PISID3-lecture/>. Разработка: `npm run dev`. `BASE_PATH` задаёт путь размещения при сборке. Через `file://` сайт не запускается.

## Интерактивный тур

Кнопка **«Тур по кнопкам»** в приложении запускает пошаговый показ элементов текущего экрана. Прямой запуск: <http://127.0.0.1:4176/2026-PISID3-lecture/?tour=1>. Тур ведёт от каталога к лекции и панели преподавателя; переход к двум окнам выполняется только по нажатию пользователя. Закрытие — крестик или Escape. В окне аудитории и печати тур скрыт. Проверка: `npm run test:tour` при работающем preview.

## Работа с материалами

**[Гайд автора: единые источники и выпуск](public/project-guide.html)** — основной порядок работы без дубляжа. **[Справка преподавателя](public/guide.html)** — управление приложением.

Определения: `authoring/original-course.json`; примеры: `authoring/worked-cases.mjs`; предметные схемы: `authoring/case-visuals.mjs`; общая логика слайдов и сценариев: `scripts/generate-content.mjs`; индивидуальные поправки заметок: `authoring/teacher-overrides.json`. `npm run generate:content` согласованно обновляет курс, задания и опубликованный пакет заметок. Браузерные черновики сначала согласуйте с авторскими источниками.

Визуализация сетевых связей использует адаптер `scripts/diagram-layout-plugin.ts` и `src/network-layout.tsx`: при обновлении движка проверьте его совместимость.

Исторические `app`, `components`, `hooks`, `lib` не входят в новую сборку. Действующий интерфейс — `src`; движок закреплён архивом `vendor/olgakraven-lecture-engine-0.2.0.tgz`. Полный сценарий `public/teacher-pack.json` публичен. Личные правки остаются в браузере; экспортируйте их перед сменой версии. Окно аудитории не загружает пакет.

Схемы показывают отношения, условия и расчёты. 416 повторных слайдов с шаблонными схемами удалены; осталось 312 визуальных разборов: 208 сравнений и 104 предметные схемы. Все 208 понятий и 416 заданий сохранены. Старые ссылки на удалённые слайды открывают соответствующее сравнение.

## Проверки

```sh
npm run generate:content
npm run check:generated
npm run check:methodology
npm run audit:content
npm run check:readiness -- --strict --teacher=public/teacher-pack.json
npm run test:notes
npm run lint
npm run build
npm run check:privacy
```

При работающем preview: `node scripts/check-startup-notes.mjs`, `npm run test:smoke`, `node scripts/render-audit.mjs`, `npm run test:visuals`. `SITE_URL` переопределяет адрес. Нужен Chromium Playwright либо Edge. Старый `scripts/audit-content.mjs` проверяет архив миграции, а не действующий курс.

PDF: `npm run export:pdf`; одна лекция: `npm run export:pdf -- --topic 16-decision-matrix`. Результат — `outputs/pdf/student`, без заметок и разборов ответов.

GitHub Actions публикует Pages после обновления `main`: пуш выполняется после утверждения предпросмотра. Офлайн-копия не включает внешние файлы Яндекс Диска. `check:privacy` проверяет отсутствие сценариев в остальных файлах сборки, а не секретность опубликованного пакета.

[Текущая редакционная проверка](docs/EDITORIAL_REVIEW.md), [исторический отчёт](docs/QUALITY.md), [источники](docs/SOURCE_AUDIT.md). РПД и официальные часы не предоставлены; время сценария не является расписанием пары.
