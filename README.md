# ПиДИС · 3 курс

26 лекций МДК.05.01 «Проектирование и дизайн информационных систем» для 5–6 семестров. Курс использует общий движок [шаблона 0.2.0](https://github.com/OlgaKraven/2026-lecture-shablone), сохраняет кейс WMS и исходные темы.

2 299 слайдов, 208 предметных понятий, 104 учебных вопроса и законченных примера, 416 заданий и 728 визуальных объяснений. В каждой лекции 88–89 слайдов и четыре вопроса. После вопроса: один ответ, два ответа из пяти, краткий ответ и соответствие четырёх пар. Обязательные ответы объяснены до теста.

## Запуск

Рекомендуется Node.js 24. Пакет общего движка закреплён локальным архивом vendor/olgakraven-lecture-engine-0.2.0.tgz и package-lock.json.

```sh
npm ci
npm run build
npm run preview -- --port 4176
```

Открыть http://127.0.0.1:4176/2026-PISID3-lecture/ . Для разработки — npm run dev. BASE_PATH при сборке позволяет изменить путь размещения; значение по умолчанию соответствует GitHub Pages. index.html не предназначен для открытия через file://.

## Проверки и PDF

```sh
npm run lint
node scripts/check-methodology.mjs
npm run check:readiness -- --strict
npm run build
npm run check:privacy
```

При работающем preview:

```sh
npm run test:smoke
node scripts/render-audit.mjs
npm run export:pdf
```

Для браузера при необходимости выполните npx playwright install chromium; в Windows предусмотрен резервный запуск Edge. SITE_URL переопределяет адрес проверяемого сайта.

PDF всех 26 лекций создаются в outputs/pdf/student. Только одна лекция: npm run export:pdf -- --topic 16-decision-matrix. Печать использует тот же движок: один слайд на страницу, без преподавательских сценариев и разборов ответов.

## Преподавательские заметки

В локальной поставке проекта private содержит 2 299 заметок: сценарий объяснения, подготовку, конспект, вопросы с ответами и оценку времени. Этот каталог исключён из Git и публичной сборки. Он передаётся преподавателю отдельным архивом.

- private/teacher-source.json — основной редактируемый источник заметок, привязанный к ID и содержанию слайдов.
- private/teacher-pack.json — полный пакет для импорта в панели преподавателя.
- private/lectures/*.json — отдельные пакеты лекций, если нужен только текущий материал.
- private/lectures/*.md — сценарии всех 26 лекций для чтения и подготовки.
- private/preparation-cards.json — карточки подготовки.
- private/editor-access.json — данные входа в редактор; не публиковать.

Откройте лекцию, нажмите «Начать занятие в двух окнах» и импортируйте TeacherPack в панели преподавателя. Полный пакет проверен: все 2 299 заметок сохраняются и доступны после перезагрузки в тестовом Chromium. При ограниченном хранилище используйте пакет нужной лекции и сохраняйте резервные копии своих правок.

Заметки дополняются сразу при изменении слайда. Команда npm run generate:content -- --teacher сохраняет существующие заметки. При изменении содержимого генератор останавливается: согласуйте заметку и её contentHash в private/teacher-source.json, затем повторите сборку. Для нового слайда требуется предметный сценарий, а не пустой шаблон. Изменения в браузере нужно экспортировать и перенести в файловый источник: localStorage не обновляет Git.

Проверка приватного комплекта: npm run check:readiness -- --strict --teacher=private/teacher-pack.json. Дополнительная проверка QR, шрифта, редактора и офлайн: node scripts/check-resources.mjs; для неё нужны приватные данные входа. Флаг --preview обновляет изображение предварительного просмотра сайта.

Редактор хранит локальный черновик. Его вход не является серверной авторизацией. Ключи учебной автономной самопроверки в assessment.json доступны посетителям технически; полный преподавательский сценарий туда не включён.

## Авторские материалы и публикация

authoring/original-course.json сохраняет исходные темы, определения и предметные указания. authoring/worked-cases.mjs содержит 104 законченных учебных примера. scripts/generate-content.mjs формирует публичные данные, задания, карту вопросов и приватные заметки. Перед повторной генерацией согласуйте изменения браузерного редактора с этими источниками.

Старые app/components/hooks/lib оставлены как исторические исходники миграции; новая сборка использует src и пакет общего движка. GitHub Actions проверяет курс, собирает dist и публикует Pages после обновления main. private и исходная инструкция с паролем не публикуются. Офлайн-режим сохраняет сайт на устройстве, но не внешние файлы Яндекс Диска.

Сохранены 19 тем пятого семестра и 7 тем шестого. РПД и официальные часы не предоставлены; оценки времени сценария не являются расписанием пары. Материалы ДЭ 2027 привязаны к соответствующим темам и не подменяют учебную программу. Источники и ограничения: docs/SOURCE_AUDIT.md. Карта 2 366 прежних слайдов: reports/migration-map.json. Отчёт проверки: docs/QUALITY.md.

### Если панель сообщает «Заметки ещё не добавлены»

Откройте [инструкцию подключения](public/guide.html#course-notes). Пакет содержит 2299 заметок для всего курса, но не загружается из публичного сайта. В панели: «Загрузить заметки» → private/teacher-pack.json → «Применить заметки». Сначала экспортируйте существующие правки кнопкой «Сохранить заметки». Импорт выполняется один раз в каждом браузере; вход в редактор его не заменяет.
